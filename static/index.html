开始注册前，请确认

1邮箱域名可用：当前 未配置，已验证能过 AWS 域名闸门。
2收信链路在线：Cloudflare catch-all → Worker → KV，验证码可自动读取。
3每个账号会真实消耗一个邮箱地址，并在 data/accounts.jsonl 留下记录。
4半自动模式下，每个号需要你人工过一次 AWS 人机验证；全自动模式尚未启用。
5同一出口 IP 连续注册有被关联的风险，建议先用 1~3 个号验证。

欢迎使用 AWS Quick 控制台

四步把这个控制台跑起来。每步都能在顶部导航找到对应页面。
1填配置：设置 → 收信配置，填邮箱域名、Worker 地址和 Token。保存即生效。
2授权第一个号：账号池 → 新增账号 → 浏览器登录（过一次人机验证）→ 粘贴回调地址。
3生成密钥：密钥 → 生成，得到 qk_…，只显示一次。
4接入：把 base_url 指向本网关的 /v1，用 OpenAI SDK 直接调用。
注册机是可选项：注册成功的号会在「注册任务」里显示，导入号池需要再授权一次。
